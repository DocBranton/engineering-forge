# Delivery roadmap

## Increment 0 — Baseline
Product identity, visual contract, architecture, acceptance criteria; review concept and target resource availability.

## Increment 1 — Application foundation
AppKit shell, mission list, engineering workspace, docked Wingman, typed API, demo fixtures isolated from operational mode. Pin validated dependencies. CI typecheck, build and tests; no deploy until explicitly authorized.
Acceptance: both desktop resolutions, dark/light theme, keyboard navigation, no fake operational metrics.

## Increment 2 — Evidence and requirements
Upload quarantine, source provenance, structured extraction, assumptions, engineer-approved requirements and alternative evaluation.
Acceptance: every requirement has evidence or a declared assumption; missing data is visible and blocks applicable tasks.

## Increment 3 — Real engineering tools
Non-flight-critical synthetic mounting bracket example. Parametric CAD, actual editable source and STEP output, deterministic dimensional/volume checks and preview.
Acceptance: generated files open in independent tools, reproducible parameters and measurements; no model-invented results.

## Increment 4 — Durable execution
Dependency-aware tasks, tool/model registry, transactional checkpoints, retry/cancel/recovery and selective rework.
Acceptance: restart recovery, no duplicate releases, invalid schema and unavailable tools fail closed, immutable revision references.

## Increment 5 — Verification and controlled release
Verification matrix, applicable analysis tools, manufacturing/repair planning, quality evidence and approved technical package.
Acceptance: mandatory checks block release unless authorized disposition policy permits; exact baseline approval; no physical verification claimed without evidence.

## Increment 6 — Governed knowledge and scale
Reusable artifacts, applicability constraints, data integration, agent evaluations, observed performance metrics, WDP resource validation and authorized release pipeline.

## Open decisions
Approved AppKit version; workspace endpoints and resources; CAD kernel and worker runtime; standards/data access; identity groups and delegated technical authority; deployment pipeline configuration. Resolve with evidence before operational deployment.
