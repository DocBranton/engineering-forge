# Increment 1 — application foundation
This branch introduces an original, demo-only implementation of the common shell and six navigation views. No private reference assets or code are copied. The UI uses neutral textual branding until approved artwork arrives. The portfolio and workspace are read-only synthetic records; other views honestly identify unimplemented capabilities. No model invocation, real CAD, persistence, upload or release is enabled.

Run npm install, npm run typecheck, npm test, npm run build, then FORGE_MODE=demo npm start. AppKit is pinned to the previously selected 0.104.0 baseline; current registry status and compatibility require validation. CI initially generates a lockfile artifact; commit a validated lockfile and switch to npm ci before merge. Visual regression screenshots, actual branding, hero art, accessibility checks and Databricks smoke testing remain outstanding. Do not deploy without authorization.
